# OVA Performances — E-commerce Store

E-commerce store built and managed on Shopify for OVA Performances. Handles product listings, inventory, payments, and customer orders for a live business.

**Live store:** [www.ovaperformances.com](https://www.ovaperformances.com)

> **Note:** This repository contains documentation and UI/UX work. Source theme files will be added in a future update.

## Tech Stack

- **Platform** — Shopify
- **Theme customization** — Liquid, HTML, CSS, JavaScript
- **Payments** — Shopify Payments (integrated processor)
- **Domain** — Custom domain via Shopify

## Work Done

### UI/UX Design
- Customized the storefront theme to match the OVA Performances brand identity
- Designed the homepage layout, product pages, and checkout flow
- Implemented responsive design for mobile and desktop shopping experiences
- Created custom sections for featured products and promotional banners

### Payment Processing
- Configured Shopify Payments as the primary payment processor
- Set up payment methods: credit/debit cards, and digital wallets
- Tested full checkout flow end-to-end including refund and order management

### Store Management
- Built and organized the product catalog with variants, pricing, and inventory tracking
- Set up collections and product tagging for navigation and search
- Configured shipping zones, rates, and fulfillment settings
- Managed order processing and customer communication
