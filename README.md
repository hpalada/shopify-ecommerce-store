# OVA Performances — Shopify E-commerce Store

Live Shopify store built for OVA Performances. Custom Liquid theme, branded UI/UX, Shopify Payments integration, and a full product catalog — processing real orders at [ovaperformances.com](https://www.ovaperformances.com).

## Stack

**Platform** — Shopify  
**Theme** — Liquid · HTML · CSS · JavaScript  
**Payments** — Shopify Payments  
**Domain** — Custom (ovaperformances.com)

## What Was Built

### Theme & UI/UX
- Custom Liquid theme built to match OVA Performances brand identity
- Homepage with featured products, promotional banners, and brand sections
- Product pages with variant selectors, image galleries, and descriptions
- Checkout flow customized for brand consistency
- Fully responsive — mobile and desktop

### Storefront
- Product catalog with variants (size, color), pricing, and inventory tracking
- Collections and product tagging for navigation and filtering
- Search and product recommendations

### Payments & Fulfillment
- Shopify Payments configured as primary processor — credit/debit, digital wallets
- Full checkout flow tested end-to-end including refunds and order management
- Shipping zones, rates, and fulfillment settings configured

### Operations
- Order processing and customer communication workflows
- Inventory tracking and stock alerts
- Sales reporting via Shopify dashboard
